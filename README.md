# DocCheck

Веб-приложение для сверки финансовых документов. Стартовый экран — «Новая проверка». На экране сверки таблица расположена рядом с документом: можно переходить между расхождениями, видеть подсвеченные суммы и проверять источник значения.

## Возможности

- Создание проверки и выбор файлов.
- Сверка таблицы с документом, вкладки полей и аннотаций, масштабирование документа.
- Переход между расхождениями, отметки проверки и комментарии.
- Заключение по проверке и экспорт результатов.
- Единый интерфейс бухгалтера с пояснениями и рекомендациями по результатам правил.

## Локальный запуск

Требуются Node.js 22 и npm 10.

```sh
git clone https://github.com/ananakimov/project-placeholder.git
cd project-placeholder
npm ci
npm run dev
```

## Проверки и сборка

```sh
npm test
npx tsc --noEmit
npm run build
```

Сборка использует TanStack Start / Nitro. Скрипт `scripts/prepare-sites.mjs` также подготавливает каталоги `dist/client` и `dist/server` для Sites.

## GitHub Pages

Сайт: [ananakimov.github.io/project-placeholder](https://ananakimov.github.io/project-placeholder/).

Изменения в `main` автоматически проходят сборку и тесты, затем публикуются через `.github/workflows/deploy-pages.yml`. В настройках репозитория Pages должен использовать источник **GitHub Actions**.

```sh
npm run build:pages
```

Эта команда создаёт статическую версию в `dist/client`. По умолчанию базовый путь — `/project-placeholder/`; переменная `PAGES_BASE_PATH` позволяет изменить его. Внутренние страницы и обновление страницы поддерживаются без серверного процесса.

## Текущее состояние

Это интерактивный прототип с заранее подготовленными данными. Выбранные файлы хранятся в памяти сессии и не обрабатываются; загрузка открывает фиксированный пример проверки. Подсветка документа основана на примерах, без OCR и серверного анализа файлов.

Пользователь — главный бухгалтер и его заместители. Роль одна: все действия бухгалтера доступны сразу, без переключателя ролей и серверной авторизации. Можно отмечать результаты проверки, редактировать предусмотренные значения, оставлять комментарии и подписывать пример заключения. Имя и время подписи сохраняются в памяти сессии; журнала действий нет.

Для расхождений и непроверенных строк показаны результат правила, возможные причины и рекомендация из подготовленных данных. Языковая модель не используется. Подтверждённые строки не содержат блока объяснения. Клик по строке открывает источник с подсветкой соответствующего фрагмента документа.

## Разработка

Стек: React 19, TypeScript, TanStack Start / Router, Tailwind CSS 4, Radix UI, Vite и Vitest.

Репозиторий связан с [проектом Lovable](https://lovable.dev/projects/9228d300-4935-4d89-928b-ec3268542aca). Изменения в `main` синхронизируются с редактором Lovable.
